# 🌍 TripSphere

### Travel Planning & Data Management Web Application

TripSphere is a full-stack travel planning web application designed to help users organize and manage travel information efficiently. The platform enables users to create travel plans, manage transportation details, and provide feedback about their travel experiences.

This project demonstrates the implementation of **Model–View–Controller (MVC) architecture, relational database design, and API integration** to build a scalable web application for travel data management.

---

# 📌 Project Objectives

The primary objective of TripSphere is to design a system that:

* Simplifies travel planning and trip organization
* Stores structured travel information using relational databases
* Demonstrates full-stack web development using modern frameworks
* Implements scalable architecture using MVC design patterns
* Integrates external data sources through APIs

# 🚀 Key Features

* Secure **user authentication and account management**
* Create, edit, and manage **travel plans**
* Store and retrieve travel information using **SQL Server**

* Integration with **external APIs** for travel information

# 🏗 System Architecture

TripSphere follows the **Model–View–Controller (MVC)** architectural pattern to ensure maintainability and scalability.

**Model**
Handles application data, database schema, and business logic.

**View**
Manages the user interface and displays travel data to users.

**Controller**
Processes user requests and connects application logic with the presentation layer.

This architecture separates concerns and improves code maintainability.

# 🗄 Database Design

The application uses a relational database to store and manage travel data.

### Core Tables

**Users**
Stores user authentication details and profile information.

**TravelPlan**
Maintains core travel data such as destination, dates, and itinerary details.

**TravelMode**
Stores transportation information including flights, trains, and road travel.

**TravelFeedback**
Captures user reviews and feedback for completed travel plans.

**ContactMessages**
Stores inquiries submitted through the contact page.
